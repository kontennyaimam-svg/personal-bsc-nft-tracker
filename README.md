# personal-bsc-nft-tracker

Personal, read-only tracker for BSC NFT collections I own or am considering.

## Purpose
- Query orders, floor prices, listings, and recent sales on Element.
- Encode trade data for a single purchase only after manual review and confirmation.
- Low volume, well within 120 requests per minute.

## Non-goals
- No resale or redistribution of Element data.
- No automated bulk trading.
- No custody of other users' assets.
